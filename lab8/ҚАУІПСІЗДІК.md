# DormMate қауіпсіздік сценарийлері

| № | Сценарий | Тексеру | Нәтиже түсіндірмесі |
|---|---|---|---|
| 1 | Бос payload | `POST /students {}` | 422 күтіледі |
| 2 | Қате JSON | `POST /students` бұзылған JSON | 422 күтіледі |
| 3 | Жоқ студент | `GET /students/99999999` | 404 күтіледі |
| 4 | Қайталанған студент нөмірі | Бірдей POST екі рет | 409 күтіледі |
| 5 | Бөлме сыйымдылығы 0 | `POST /rooms` capacity=0 | 422 күтіледі |
| 6 | Рұқсатсыз API | Бастапқы жобада login/auth жоқ | 401/403 **тексерілді деп есептеуге болмайды**; бұл — қауіпсіздік кемшілігі |
| 7 | Рөлсіз admin әрекеті | Бастапқы жобада рөл модулі жоқ | Бөлек қорғау модулін әзірлеу қажет |

Bandit статикалық тексерісі: `python -m bandit -r app`.

Жүктемені тек өзіңнің жергілікті серверіңе бағытта. CI/CD-тағы security scanning авторизация мен рөлдік қорғауды алмастырмайды.
