**Жоба:** DormMate — жатақхана орындары мен өтініштерді басқару жүйесі

## Мақсаты
FastAPI, SQLite және Streamlit негізіндегі жобаның API интеграциясын, дерек тұтастығын, жүктеме кезіндегі тұрақтылығын және қауіпсіздігін тексеру; pytest пен GitHub Actions арқылы автоматтандыру.

## 1. Архитектура
`АРХИТЕКТУРА.md` файлы. Streamlit → FastAPI → SQLModel/SQLite. Тестілеу: pytest/TestClient, Locust, Bandit, GitHub Actions.

## 8. Кемшіліктер мен ұсыныстар
- Авторизация, әкімші/студент рөлдерін және 401/403 тексерісін енгізу.
- Күрделі жүктемеде SQLite жазу құлпының ықтимал әсерін бақылау, қажет болса PostgreSQL қарастыру.
- Жүктемені нақты өлшеу, қателерді түзету және қайта тест өткізу.

## Қорытынды
Қосымша тест файлдары мен CI/CD конфигурациясы әзірленді. Жұмыстың нақты нәтижесі орындалған сынақтар мен GitHub Actions журналымен толықтырылады.
