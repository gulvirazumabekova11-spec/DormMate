**Орындаған:** Жұматай Нұрсая

**Жоба:** DormMate — жатақхана орындары мен өтініштерді басқару жүйесі

## Мақсаты
FastAPI, SQLite және Streamlit негізіндегі жобаның API интеграциясын, дерек тұтастығын, жүктеме кезіндегі тұрақтылығын және қауіпсіздігін тексеру; pytest пен GitHub Actions арқылы автоматтандыру.

## 1. Архитектура
`АРХИТЕКТУРА.md` файлы. Streamlit → FastAPI → SQLModel/SQLite. Тестілеу: pytest/TestClient, Locust, Bandit, GitHub Actions.

## 8. Анықталған қателер және оларды түзету жолдары

Тестілеу барысында төмендегі жағдайлар анықталды:

1. Бос деректер жіберілгенде сервер 422 кодын қайтарды.
   Бұл — дұрыс нәтиже, себебі міндетті өрістер толтырылмаған.

2. Қате JSON форматы 422 кодымен қабылданбады.
   Деректерді тексеру дұрыс жұмыс істейді.

3. Жоқ бөлме сұралғанда 404 қатесі қайтарылды.
   Сервер жоқ жазбаны дұрыс анықтайды.

4. Қайталанған студент нөмірі 409 кодымен қабылданбады.
   Қайталанатын деректерден қорғау жұмыс істейді.

5. Жүктемелік тестілеуде қате сұраныстар тіркелмеді.
   Қарастырылған сценарийлерде сервер тұрақты жұмыс істеді.

Ұсыныстар:
- Авторизация және пайдаланушы рөлдерін енгізу.
- Қауіпсіздік тесттерін кеңейту.
- Сервердің CPU және RAM жүктемесін бақылау.
- Жүктемелік тестілеуді әртүрлі жағдайларда қайталау.
