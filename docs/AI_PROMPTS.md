# AI-ассистентке берілген промпттар үлгісі

1. «Жатақханадағы бос орындар мен өтініштерді басқару жүйесіне арналған ER диаграмма құрастыр. Student, Room, Application кестелерін, өрістерін және кардиналдылығын негізде.»
2. «Осы ER сызбасына SQLModel кестелерін және StudentCreate/Update, RoomCreate/Update, ApplicationCreate/Update схемаларын жаса. PATCH схемасында барлық өзгеретін өрістер Optional болсын.»
3. «FastAPI роутерлерін әзірле: тізімді алу, ID бойынша оқу, POST, PATCH, DELETE. GET сүзгілері параметр арқылы берілсін; жоқ жазбаға 404, байланыс шектеуіне 409 бер.»
4. «Streamlit арқылы бөлме тізімі мен ақы бойынша сүзгі, студентті тіркеу, жатақхана өтінішін беру және мәртебесін өзгерту интерфейсін жаса.»

ИИ ұсынған кодты қолданысқа енгізер алдында өріс байланысын, енгізу валидациясын және қате жағдайларын қарап шығыңыз.
